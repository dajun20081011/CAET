# CAET V1 已知问题

## 高优先级

### 1. 音频资源
- **问题**: 当前使用浏览器 TTS 作为音频兜底方案，音质和一致性与专业录音有差距
- **影响**: 学习体验
- **建议**: 提前录制/生成 MP3，按 `audio/{course}/{id}-normal.mp3` 和 `audio/{course}/{id}-slow.mp3` 存放
- **状态**: 待外部资源制作

### 2. Supabase 外部依赖
- **问题**: 项目需要真实的 Supabase 项目 URL 和 Anon Key 才能连接后端
- **影响**: 当前所有数据使用 mock，多用户场景无法验证
- **建议**: 创建 Supabase 项目并配置环境变量
- **状态**: 待用户提供/配置

### 3. 语音转写兼容性
- **问题**: Web Speech API 在 Safari 和 Firefox 中支持有限或不一致
- **影响**: 周测中译英口述转写功能在部分浏览器不可用
- **建议**: 提供降级方案（纯文本输入对照），或引导用户使用 Chrome/Edge
- **状态**: 需要 polyfill 或替代方案

## 中优先级

### 4. 录音格式
- **问题**: 当前使用 webm 格式，iOS Safari 可能不支持播放
- **影响**: 录音回放在 iOS 设备可能失败
- **建议**: 检测浏览器类型，使用 MP4 或 WAV 格式
- **状态**: 可优化

### 5. 有效学习时长精度
- **问题**: 心跳机制每 20 秒累计一次，可能遗漏短暂交互
- **影响**: 统计精度
- **建议**: 可考虑更细粒度（如 5-10 秒）或结合页面 visibility 做更精确计算
- **状态**: 当前方案可接受

### 6. PWA 功能不完整
- **问题**: 仅配置了 meta 标签，缺少 service worker 和离线缓存
- **影响**: 无法离线学习
- **建议**: 添加 vite-plugin-pwa 或手动编写 service worker
- **状态**: 可后续增强

## 低优先级

### 7. 图片资源
- **问题**: 登录页、任务中心等情绪节点使用占位符/纯色背景，缺少航空主题配图
- **影响**: 视觉体验
- **建议**: 添加高质量航空/客舱服务主题图片
- **状态**: 待设计资源

### 8. 动画与过渡
- **问题**: 页面切换和组件过渡动画较少
- **影响**: 用户体验流畅度
- **建议**: 添加 Vue Transition 和 CSS 动画
- **状态**: 可优化

### 9. 管理员权限细化
- **问题**: 当前仅区分 admin/learner，无更细权限控制（如仅查看、仅发布等）
- **影响**: 多管理员场景权限管理
- **建议**: 添加 roles 表或权限字段
- **状态**: V2 可考虑

### 10. 数据导出格式
- **问题**: CSV 导出为简单逗号分隔，复杂 JSON 字段未完全展开
- **影响**: 数据分析便利性
- **建议**: 导出时展开 JSON 字段为独立列，或支持 Excel 格式
- **状态**: 可优化
