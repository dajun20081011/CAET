# CAET 发布包目录

所有可交付文件统一由 `scripts/生成发布包.ps1` 生成并分类保存：

- `部署包/`：完整构建产物及部署配置。
- `修复包/`：单项功能修复文件、补丁和说明。

每次发布会创建 `部署/名称-版本` 或 `修复/名称-版本` 中文 Git 分支。只有明确传入 `-同步GitHub` 时，脚本才会提交并推送，便于先本地验包。

## 示例

```powershell
# 生成并同步完整部署包
./scripts/生成发布包.ps1 -类型 部署包 -名称 正式环境 -版本 v1.2.1 -说明 '正式环境部署' -同步GitHub

# 生成功能修复包（相对 origin/main 收集改动）
./scripts/生成发布包.ps1 -类型 修复包 -名称 登录超时 -版本 v1.2.1-fix1 -说明 '修复登录状态提前失效' -同步GitHub
```

归档命名：`发布包/<类型>/<名称>-<版本>.zip`，同目录保存中文说明和 SHA256 校验值。
